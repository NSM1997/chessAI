# Explainable Chess AI - Browser Extension

A browser extension that provides **real-time chess analysis with AI-powered explanations** while playing on Chess.com and Lichess. Get instant move suggestions powered by Stockfish, tactical pattern recognition using deep learning, and natural language explanations generated by LLMs.

![Chess AI Extension Demo](docs/demo.gif)

## ✨ Features

- 🎯 **Real-time Analysis**: Captures board position and provides instant move suggestions
- 🧠 **Stockfish Engine**: Professional-grade position evaluation up to depth 20
- 🤖 **AI Explanations**: Natural language explanations powered by Ollama (llama3.2) or OpenAI GPT-4
- 🎓 **Tactical Pattern Recognition**: Deep learning CNN model trained on 20+ tactical themes
- 📊 **Position Evaluation**: Comprehensive board analysis including threats, hanging pieces, and piece activity
- 🎮 **Platform Support**: Works on Chess.com
- ⚡ **Fast & Responsive**: Overlay UI with minimal performance impact

## 🚀 Quick Start

### Prerequisites

- **Python 3.8+** (tested with 3.12-3.13)
- **Chrome/Edge** browser
- **Stockfish** chess engine
- **Ollama** (for local LLM explanations) OR **OpenAI API key** (optional)
- **4GB+ RAM** recommended

### Installation Steps

#### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/explainable-chess-ai.git
cd explainable-chess-ai
```

#### 2️⃣ Install Python Dependencies

```bash
# Install core backend dependencies
pip install -r backend/requirements.txt

# Install LLM dependencies (for explanations)
pip install ollama
```

#### 3️⃣ Download and Setup Stockfish

**Windows:**
```powershell
# Download Stockfish from https://stockfishchess.org/download/
# Extract to stockfish/ directory
# Example: stockfish/stockfish-windows-x86-64-avx2.exe
```

**macOS:**
```bash
brew install stockfish
# Or download from https://stockfishchess.org/download/
```

**Linux:**
```bash
sudo apt-get install stockfish
# Or download from https://stockfishchess.org/download/
```

The server will automatically detect Stockfish in:
- `stockfish/` directory
- System PATH
- Common installation locations

#### 4️⃣ Install and Setup Ollama (for AI Explanations)

**Windows:**
```powershell
# Download Ollama from https://ollama.com/download
# Run the installer OllamaSetup.exe
# After installation, open a new terminal

# Pull the llama3.2 model
ollama pull llama3.2
```

**macOS/Linux:**
```bash
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Pull the model
ollama pull llama3.2
```

**Alternative: Use OpenAI API (Optional)**
```bash
# Set your OpenAI API key
export OPENAI_API_KEY="sk-your-api-key-here"  # Linux/Mac
$env:OPENAI_API_KEY = "sk-your-api-key-here"  # Windows PowerShell
```

#### 5️⃣ Start the Backend Server

```bash
# Using the simple server (recommended)
python simple_server.py

# Server will start at http://localhost:8001
```

You should see:
```
[SUCCESS] Stockfish engine initialized successfully!
[SUCCESS] Tactical classifier initialized with 20 themes!
[SUCCESS] Board analyzer initialized successfully!
[INFO] No API key found, using Ollama with llama3.2
[SUCCESS] LLM explanation service initialized (provider: ollama-local)!
```

#### 6️⃣ Install Browser Extension

1. **Open Chrome/Edge**
2. Navigate to `chrome://extensions/` or `edge://extensions/`
3. Enable **"Developer mode"** (toggle in top-right)
4. Click **"Load unpacked"**
5. Select the `frontend/` directory from this project
6. The extension icon should appear in your toolbar

#### 7️⃣ Test the Extension

1. Visit [Chess.com](https://chess.com) or [Lichess.org](https://lichess.org)
2. Start a game or open a puzzle
3. An overlay should appear on the right side showing:
   - Best move suggestion
   - Position evaluation
   - AI-powered explanation
   - Tactical motifs detected
   - Strategic concepts

## 🔧 Troubleshooting

### Extension Not Working

**Problem:** Extension doesn't show overlay on chess site

**Solutions:**
1. Check backend server is running: `http://localhost:8001/health`
2. Open browser console (F12) and check for errors
3. Verify extension is loaded: `chrome://extensions/`
4. Reload the extension
5. Hard refresh the chess website (Ctrl+Shift+R)

### Stockfish Not Found

**Problem:** `[ERROR] Failed to initialize chess engine`

**Solutions:**
1. Download Stockfish from https://stockfishchess.org/download/
2. Place executable in `stockfish/` directory
3. Make sure file is executable (Linux/Mac: `chmod +x stockfish`)
4. Check server logs for exact path being searched

### Ollama Connection Issues

**Problem:** `Ollama not running or not accessible`

**Solutions:**
1. Verify Ollama is installed: `ollama --version`
2. Check Ollama service is running: `ollama list`
3. Pull the model: `ollama pull llama3.2`
4. Test manually: `ollama run llama3.2`
5. Check Ollama is accessible at: `http://localhost:11434`

### Slow Explanations

**Problem:** Explanations take 15+ seconds

**Solutions:**
1. **Use smaller model**: llama3.2 is already the fastest
2. **Reduce token limit**: Edit `llm_explanation.py` line 272: `num_predict: 30`
3. **Use fallback**: Edit `simple_server.py` line 88: `provider="fallback"`
4. **Get OpenAI API key**: Much faster with GPT-4

### CORS Errors

**Problem:** `Access-Control-Allow-Origin` errors in console

**Solutions:**
1. Server already has CORS enabled for all origins
2. Make sure server is running on port 8001
3. Check extension's API URL in `chess-analyzer.js`

python scripts/train_tactical_model.py \
  --data data/lichess_puzzles.csv \
  --epochs 50 \
  --batch-size 32

### Using Different Ollama Models

```python
# Edit backend/app/services/llm_explanation.py line 267
model='qwen2.5:7b',  # Try: llama3.1:8b, mistral, etc.
```

### Custom Board Analysis

```python
from backend.app.services.board_analyzer import BoardAnalyzer
import chess

analyzer = BoardAnalyzer()
board = chess.Board("rnbqkbnr/pppppppp/8/8/4P3/8/PPPP1PPP/RNBQKBNR b KQkq e3 0 1")

analysis = analyzer.analyze_position(board)
print(f"Hanging pieces: {analysis['hanging_pieces']}")
print(f"Threats: {analysis['threats']}")
```
